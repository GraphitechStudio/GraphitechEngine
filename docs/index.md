# Documentation — Graphitech ECS

Bienvenue dans la documentation publique du système ECS du projet Graphitech.

Ce site contient :

- Une RFC décrivant l'architecture et les invariants de l'ECS.
- Un guide pour contribuer au développement de l'ECS.
- La documentation API par fichier d'en-tête (un `.md` par `.hpp`) décrivant chaque fonction et fournissant des exemples d'utilisation indépendants du code source.

Utilisez le menu (`docs/SUMMARY.md`) afin de naviguer entre les sections.

Références rapides :

- Code source faisant appel à l'ECS : `Rendering/SceneRenderer.cpp`, `Application/GameApplication.hpp`.
- Exemple d'utilisation (renderer) : `Rendering/SceneRenderer.cpp`.
